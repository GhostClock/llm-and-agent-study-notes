## 二、WorkBuddy 是什么

- **WorkBuddy 是腾讯推出的全场景职场 AI 智能体桌面工作台**。
- 你只需**用一句话描述需求**，它便能像同事一样**自主规划和执行复杂任务**，并交付可验收的结果。
- 与传统的 AI 对话不同，它不仅能"听懂人话"，还能"**带脑子思考**"并"**实际操作本地文件**"。
- 官方教程文档：https://www.workbuddy.cn/docs/workbuddy/Overview

### 2. 界面各区域功能

- **侧边栏**：显示功能与任务列表；**对话区**：核心交互区域。
- 关键操作：**功能场景切换**（日常办公 / 代码开发 / 设计创意）、**快捷指令**、**对话框**、**模型选择**、**工作空间**、**权限设置**。

<img src="images/s07_WorkBuddy界面功能区域.png" width="780" alt="WorkBuddy 界面功能区域">

### 3. 创建任务

- **核心优势是理解自然语言**，一句话描述需求即可自主规划和执行。
- 示例：
  - "帮我把这份销售数据生成一个分析报告，包含图表"
  - "整理 Downloads 文件夹里的图片，按日期分类"
  - "分析这份简历，提取关键信息生成表格"
  - "调研一下 2026 年 AI 行业趋势，写一份报告"

<img src="images/s08_WorkBuddy创建任务示例.png" width="780" alt="WorkBuddy 创建任务：对话区 + 结果区">

### 4. 工作空间

- 用于管理任务与文件的存放位置，可选择已有工作空间或**新建 / 打开本地文件夹**。

<img src="images/s09_选择工作空间.png" width="320" alt="选择工作空间">

**WorkBuddy 核心功能可拆成三层**：干活的执行内核、能持续扩展的能力层、围绕交付的协作层。

<img src="images/s09_WorkBuddy核心功能地图.png" width="780" alt="WorkBuddy 核心功能地图">

### 5. 连接器（Connector）

- 连接器用于把 WorkBuddy 与**外部服务对接**，实现数据互通与能力扩展。
- 配置后可直接访问和操作第三方服务（如腾讯文档、QQ 邮箱、企业微信、飞书、钉钉等）。

<img src="images/s10_连接器广场.png" width="780" alt="WorkBuddy 连接器广场">

以 **QQ 邮箱**为例：

<img src="images/s10_启用QQ邮箱连接器.png" width="780" alt="启用 QQ 邮箱连接器">

<img src="images/s10_查询邮箱内容示例.png" width="780" alt="用 WorkBuddy 查询最近邮箱内容">

### 6. 技能（Skill）

- **技能为 WorkBuddy 增加"特定工具能力"**：封装一组可执行的脚本与工作流，让 AI 在你的授权下完成具体动作（发邮件、订外卖、查股价、读写文件、调用第三方 API 等）。

<img src="images/s11_技能中心SkillHub.png" width="780" alt="技能中心 SkillHub">

### 7. 专家（Expert）与专家团

- **专家**：为 WorkBuddy 配置专业角色，以"人设 + 方法论 + 工具链"让 AI 用专家身份执行任务（**角色切换**机制）。
- **专家团**：由多位专家分工协作，由团长自动拆解、并行执行并整合交付（**协作执行**机制）。

<img src="images/s12_专家与专家团.png" width="780" alt="专家与专家团">

### 8. Skill VS 专家 VS 专家团

- **Skill 是能力**（让 AI 能做某件事）
- **专家是能力 + 经验**（Agent 型）
- **专家团是多位专家 + 协作流程**（Team 型）

> 怎么选：需要工具能力 → **装 Skill**；有明确单点问题 → **找专家**；任务复杂需多角色配合 → **召唤专家团**。

<img src="images/s13_Skill专家专家团关系图.png" width="620" alt="Skill / 专家 / 专家团 关系与选择">

## 五、Vibe Coding（氛围编程）

### 什么是 Vibe Coding

- **Vibe Coding（氛围编程）是一种依托大语言模型（LLM）的高效开发新范式**。
- 开发者通过**自然语言**描述需求与逻辑，AI 即可辅助完成**代码生成、调试优化、迭代重构**的全流程，实现"以言代码"的人机协作新模式。

<img src="images/s18_什么是VibeCoding.png" width="760" alt="什么是 Vibe Coding">

### 三大特点

<table>
  <tr>
    <td align="center"><img src="images/s18_VibeCoding优势01效率倍增.png" width="270" alt="效率倍增"></td>
    <td align="center"><img src="images/s18_VibeCoding优势02门槛降低.png" width="270" alt="门槛降低"></td>
    <td align="center"><img src="images/s18_VibeCoding优势03核心挑战.png" width="270" alt="核心挑战"></td>
  </tr>

- **效率倍增 · 极速落地**：把"需求到原型"的周期从数天压缩至小时级。
- **门槛降低 · 全民共创**：无需精通编程语言，自然语言即可与 AI 协作开发。
- **核心挑战 · 可控性博弈**：AI 输出有随机性与"幻觉"风险，**高质量 Prompt 是开发者的核心必修课**。

- **项目定位**：贴合学员真实学习场景的**轻量级工程化项目**，具备完整前后端交互架构与本地数据安全存储能力，集**智能问答、资源管理、学习评估**于一体。

- **核心原则：先简后繁，夯实基础** —— 先实现简单方案，再逐步优化；优先保证核心功能可用与稳定，避免过度设计。

## 八、开发实操与规范

### 1. 整体技术架构

- **核心架构模式：前后端分离** —— 前端 HTML5 + CSS3 + JS 轻量应用；后端 Python Flask 服务端。

<img src="images/s34_前后端分离架构.png" width="780" alt="核心架构模式：前后端分离">

### 2. AI 赋能：自动化产出关键设计文档

- **接口规范**：自动梳理全量 API 端点清单，明确请求参数、响应格式与错误码。
- **数据持久化**：智能推导数据库表结构、字段类型及表间关联关系。

<img src="images/s34_AI自动产出设计文档.png" width="780" alt="AI 赋能：自动产出关键设计文档">

### 4. 开发实操流程

**第 1 步：发送基础需求指令**

- 清晰描述项目目标（如"AI 学习助手"），并列举核心功能：资料传输、文档对话、能力测评、进度追踪、自动周报。
- ⚠️ **核心红线**：必须明确"**禁止发散需求**"与"**禁止提前启动开发**"，严控范围蔓延。

- 要求 AI 输出结构化文档：功能点拆解与 P0/P1 优先级划分、后台 API 接口清单、数据库表结构设计、多场景系统提示词配置。

<img src="images/s36_实操02指令升级生成文档.png" width="780" alt="实操第 2 步：指令升级生成完整文档">

**第 3 步：需求评审与确认**

- 开发者与产品方共同评审，核验需求完整性、逻辑合理性与技术可行性，消除歧义。

<img src="images/s36_实操03需求评审与确认.png" width="780" alt="实操第 3 步：需求评审与确认">

**第 4～6 步：前端开发 → 后端开发 → 前后端联通**

- 先做**前端开发**（所见即所得，能持续提供正向激励）；
- 再做**后端开发**（前端定型后 API 与数据结构更明确，避免返工）；
- 最后**前后端联通**（确保有可视化成果，降低开发风险）。
